# Resolve AI Data

The Orange Summer Challenge MVP uses synthetic data only.

This directory will contain sample datasets used to demonstrate:

- customer bundle activity;
- behavioral changes;
- feedback;
- reason classification;
- recommendations;
- interventions;
- outcomes.

The datasets in this repository do not represent Orange Liberia's
production database schema or real customer information.

Any production integration would require an approved mapping layer,
data-access authorization, and Orange privacy/security review.
